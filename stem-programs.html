For Parents & Students (Grades 5 – 12)

Hands-On STEM & 3D CAD Mentorship

Structured 1-on-1 and small-group tutorials designed to build real-world fluency in Python coding, parametric 3D CAD, product design, and web development.

Track 01 • Coding

Programming & Computational Thinking

Students learn clean programming fundamentals through Python, algorithmic logic, and practical automation scripts rather than passive copy-paste drills.

  • Variables, data structures, loops, and modular functions
  • Structured problem decomposition & debugging habits
  • Interactive apps, data processing & robotics logic
Track 02 • 3D CAD

3D CAD Modeling & Additive Design

Learn industry-standard parametric 3D modeling workflows—from constrained 2D sketches to multi-part assemblies ready for 3D printing.

  • Parametric feature trees & dimension-driven design
  • Multi-part assemblies, fits, and tolerances
  • Slicing & Design for 3D Printing (FDM / SLS basics)
Track 03 • Design Thinking

Product Design & Prototyping

Bridging creativity and functionality. Students take an everyday problem, sketch concepts, build digital models, and test physical prototypes iteratively.

  • User-centered problem framing & sketching
  • Material selection & manufacturability basics
  • Iterative prototype testing and refinement
Track 04 • Web Dev

Webpage Coding & Interactive Apps

Students build responsive websites from scratch using modern HTML5, CSS3, and JavaScript, learning how real web applications are structured and deployed.

  • Semantic HTML & responsive CSS Grid/Flexbox layouts
  • JavaScript DOM manipulation & interactive logic
  • Hosting live student portfolios on GitHub Pages
